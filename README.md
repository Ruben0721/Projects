# Projects

- [chavez-steel](chavez-steel/) - website for Chavez Steel Houston LLC (English / Spanish). Open `chavez-steel/index.html` in a browser.
- [signs-printing](signs-printing/) - Metal Max sign site for Signs & Printing, 4528 Hwy 6 N, Houston (English / Spanish). Pages: `index.html` (home), `design.html` (sign designer with live 3D preview), `checkout.html` (cart + checkout preview, not connected to payments yet), `about.html`. Temporary prices are in `assets/pricing.js`; Zelle / Cash App settings at the top of `assets/checkout.js`. Run it from a local server (e.g. `python3 -m http.server`) so the designer can load fonts and photos.
- [sr-global](sr-global/) - redesign of srglobalmultiservices.com (English / Spanish). Open `sr-global/index.html` in a browser.
- [kiwi-energy](kiwi-energy/) - redesign of kiwienergy.com. Open `kiwi-energy/index.html` in a browser.
